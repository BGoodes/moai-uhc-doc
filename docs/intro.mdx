# Bienvenue

Bienvenue sur la documentation de **Moai UHC**, votre guide pour découvrir et jouer en UHC sur Hytale.

Ce guide est conçu pour les joueurs de tous niveaux, que vous soyez un débutant ou confirmé. Il permettra 
aussi dans le futur d'obtenir des informations sur les différents modes de jeu *qui n'existent pas encore*,
les scénarios *qui n'existent pas encore non plus* et sur comment configurer la partie.


### À propos de cette documentation

Cette documentation est amenée à évoluer avec Hytale et le serveur. De nouvelles pages seront ajoutées afin de couvrir les nouvelles mécaniques de jeu,
fonctionnalités et stratégies. Mais aussi pour couvrir les potentiels nouveaux modes de jeu, scénarios, ...

:::info

**Un problème, une erreur ou une information manquante ?** Tout le monde peut contribuer, même sans être développeur. Toutes les explications sont dans 
le [guide de contribution](https://github.com/BGoodes/moai-uhc-doc/blob/main/CONTRIBUTING.md).

:::
