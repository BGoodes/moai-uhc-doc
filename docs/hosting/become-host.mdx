# Comment devenir Host
Quand un partie n'a pas d'host, le serveur bloque les joueurs n'ayant pas la permission d'héberger la partie. Si la permission
vous est accordée, vous pourrez vous connecter et débloquer le serveur en devenant l'host de la partie. Pour cela, vous devez
utiliser la commande commande : `/uhc host`.

Des permissions vous serons accordées en tant qu'host et vous aurez donc accès a diverses commandes précisés dans la section 
[Commandes](./commands.mdx).
